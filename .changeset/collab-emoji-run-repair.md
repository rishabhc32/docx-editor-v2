When concurrent edits in a shared room leave an emoji's text without a run, the emoji stays in one run, so the room keeps saving and every participant keeps the same document. Breaking collaboration upgrade: rooms of earlier formats must be exported and reseeded; see [Upgrade rooms to format 1.4.4.2](https://www.docx-editor.dev/docs/2.x/pro/collaboration-versions#upgrade-rooms-to-format-1442).
