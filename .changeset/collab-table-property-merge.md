Collaboration merges concurrent changes to one table row's or cell's properties, such as row heights, cell fills, borders, and column widths, into one valid table that everyone can keep editing. Breaking collaboration upgrade: rooms of earlier formats must be exported and reseeded; see [Upgrade rooms to format 1.4.3.1](https://www.docx-editor.dev/docs/2.x/pro/collaboration-versions#upgrade-rooms-to-format-1431).
