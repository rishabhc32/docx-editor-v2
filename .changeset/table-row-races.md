When two people in a shared room suggest formatting changes to one table row at the same time, the earlier suggestion keeps the row and the later one is removed with an explanation, and table formatting suggestions wait for the connection while offline. Breaking collaboration upgrade: rooms of earlier formats must be exported and reseeded; see [Upgrade rooms to format 1.4.3.1](https://www.docx-editor.dev/docs/2.x/pro/collaboration-versions#upgrade-rooms-to-format-1431).
