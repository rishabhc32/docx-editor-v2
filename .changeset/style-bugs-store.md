A paste or Enter over a content control's prompt keeps a field or a comment elsewhere in the paragraph. A tracked row height keeps the row's own table settings, and Reject restores them. Accepting a tracked new table or row leaves no empty paragraph properties. Removing a custom node from a header also removes its stored data. A pasted SmartArt whose drawing part is damaged no longer points at an unrelated relationship. A text box in a file that repeats paragraph ids keeps unique ids.
