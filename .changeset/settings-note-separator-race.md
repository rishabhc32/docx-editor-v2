When two people in a shared room add the first footnote or endnote at the same time, the document keeps one set of note settings and stays valid for Word. Breaking collaboration upgrade: rooms of earlier formats must be exported and reseeded; see [Upgrade rooms to format 1.4.4.2](https://www.docx-editor.dev/docs/2.x/pro/collaboration-versions#upgrade-rooms-to-format-1442).
